# Plan: agents that outlive the window, and features from T3 Code

Goal (2026-11-22): port the eight T3 Code features picked in the review, and
add three more: agents keep working while Glaude is closed, a terminal
inside the conversation, and opening linked files and folders from the app.

Status: all eleven are implemented (see the README features list and the
host protocol in `protocols.md`).

## 1. Agent host (agents keep working when the app is closed)

Today the app process owns every `claude`/`codex` process and kills them on
exit. A separate **host** process takes that job:

- Same binary, started as `glaude --host` (detached: own session/process
  group, no stdio). The app starts it when none is running.
- Local socket: a Unix socket in the app data folder (mode 0600), or the
  named pipe `\\.\pipe\glaude-host-<user>` on Windows. A random token in a
  0600 file must be presented in `hello`.
- JSON lines. Requests `{id, method, params}` → `{id, ok}` / `{id, error}`;
  events `{conv, events}` for conversations a client attached to.
- The host keeps a **snapshot** of each conversation (items, session,
  limits, tasks, turn state) by applying the same events the UI applies, so
  a client that (re)attaches gets `reset` + `session` + `limits` + tasks +
  `turn` first, then the live stream.
- Lifetime: while a client is connected nothing changes. With no client, an
  idle conversation is stopped at once; a busy one (turn running, background
  tasks, queued messages, a scheduled resume) keeps going and is stopped
  when it becomes idle. A conversation waiting for a permission or question
  keeps its process for 6 hours. The host exits a minute after its last
  conversation and client are gone.
- Version: `hello` carries the protocol version and the app binary stamp.
  An outdated host with nothing running is replaced; one with running work
  keeps serving (same protocol) until it is idle.
- The UI saves each conversation's start spec, so tabs come back after a
  restart: attached live if the host still runs it, otherwise resumed from
  the transcript when opened.

## 2. Queue and steer
Sending while a turn runs **queues** the message (shown above the composer:
edit, remove, send now). The queue lives in the host, so it drains while the
app is closed. Cmd/Ctrl+Enter **steers** instead: Codex `turn/steer`;
Claude takes the message mid-turn.

## 3. Resume at limit reset
A turn that ends on a usage limit marks the conversation *Limited until
<reset>*, with **Resume at reset** (host timer, sends "continue").

## 4. Composer
ArrowUp/ArrowDown walk earlier prompts (empty composer or caret on the first
line); Cmd/Ctrl+S stashes the draft (stash menu to restore); selecting text
in a reply offers **Quote** (inserts a `>` quote).

## 5. Side chat
`/btw <question>` or the menu item opens a fork of the conversation in a
split pane; **Add to chat** quotes its last answer into the main composer.

## 6. Links to files and folders
Paths in replies (links, `file://`, inline code like `src/a.ts:12`) that
exist become clickable: open in the editor (setting: default app, VS Code,
Cursor, Zed), reveal in Finder/Explorer, open a terminal there (folders),
or view in a read-only tab.

## 7. Terminal in the conversation
A terminal drawer under the conversation (Ctrl+\`), started in its folder.

## 8. Changes pane
A **Changes** tab per project folder: Uncommitted, Branch (vs. the default
branch) and Commits; filter by path or text; comment on a line and send the
review to the conversation.

## 9. Git actions
In the Changes tab: commit (message typed or generated by a one-shot
`claude -p --model haiku`), push, create a PR (`gh pr create`).

## 10. Worktree conversations and project actions
New-conversation option *in a new worktree* (`git worktree add`, branch name
from the title). `.glaude.json` in the project:
`{"worktree": {"setup": "...", "cleanup": "..."}, "actions": [{"name": "Dev", "command": "..."}]}`.
Actions run in a terminal tab from the statusline.

## 11. Conversation triage
Sidebar sessions can be pinned, snoozed (1 h, tonight, tomorrow, next week)
and archived (toast with Undo). Cmd+K ranks results by frecency.
