The first public release of Glaude: a desktop app for Claude Code and Codex, built for Persian and other right-to-left text.

**Download:** the `.dmg` for macOS (universal: Apple silicon and Intel), the `-setup.exe` or `.msi` for Windows, and the `.AppImage`, `.deb` or `.rpm` for Linux. `SHA256SUMS.txt` lists the checksums.

### Before you start

Glaude runs the `claude` and/or `codex` CLI that is already installed and signed in on your computer. There is no separate login and no API key.

**macOS:** this build is not notarized yet. On first launch macOS says it can't check the app. Open **System Settings → Privacy & Security** and choose **Open Anyway**. Or run `xattr -dr com.apple.quarantine /Applications/Glaude.app` once.

### Highlights

- **Conversations** with Claude Code and Codex: streaming replies, thinking, tool calls, plans, subagents and workflows.
- **Right-to-left done properly.** Every block gets its own direction, and code stays left to right. Persian is set in Estedad, and the composer follows what you type.
- **Agents keep working when the window is closed.** A background host keeps turns, queued messages and scheduled resumes going.
- **Approve in place.** Permission cards show the diff. Questions and plans become forms.
- **Workspace:**
  - splits and tabs (up to eight panes);
  - an agents board;
  - a VS Code-style terminal panel;
  - the Changes tab, with review notes, commit, push and pull request;
  - worktree conversations.
- **Accounts:** many Claude and Codex accounts, with plans, 5-hour and weekly limits, and usage.
- **Organization:**
  - projects;
  - history search with Persian normalization;
  - a command palette with saved prompts;
  - proxies per app, account, project or conversation.
- **Themes:** about 25 light and dark themes for the window, the code and the terminal. Pick any accent, give chats and terminals their own theme, and import themes from VS Code, iTerm2, Ghostty, kitty or Windows Terminal.

Glaude is independent and not affiliated with Anthropic or OpenAI.
